## 🎨 Sobre o Projeto

Este projeto consiste em um formulário interativo de pedidos de pizza desenvolvido com HTML5 e CSS3. A interface foi totalmente reformulada para adotar um design contemporâneo baseado em **Glassmorphism** (efeito de vidro fosco), sobreposto a um fundo imersivo e elegante.

### ✨ Principais Funcionalidades:
- **Seleção de Tamanhos:** Opções claras de tamanhos de pizza (Pequeno, Médio, Grande).
- **Escolha de Sabores:** Menu suspenso (`select`) estilizado com os sabores disponíveis.
- **Adicionais Personalizados:** Caixas de seleção para itens extras (borda recheada, queijo extra).
- **Agendamento:** Campo de data para programar a entrega.
- **Observações:** Área de texto livre para comentários e sugestões.

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram empregadas no desenvolvimento da página:

* **HTML5:** Estruturação semântica do formulário e das tags de conteúdo.
* **CSS3:** Estilização avançada, utilizando:
  * **Flexbox** para alinhamento e distribuição de elementos.
  * **Backdrop-filter** para o efeito visual de vidro translúcido.
  * **Gradientes lineares** para sobreposição e contraste no plano de fundo.
* **Google Fonts:** Tipografia moderna utilizando a fonte *Inter*.
